# Colour-vision-deficiency checks

Simulate how colours, palettes and whole figures look to readers with a
colour-vision deficiency, and in greyscale print. The simulations use the
Machado, Oliveira & Fernandes (2009) model and need no extra packages. See
{doc}`../colors` for the guide.
